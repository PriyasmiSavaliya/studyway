# StudyWay 🎓

## Description
StudyWay is a college and course recommendation system designed to help students find suitable colleges in India based on their interests and preferences. The platform analyzes factors such as entrance exams, course fees, college locations, and ratings to provide personalized and relevant recommendations. It aims to simplify the college selection process and support students in making informed academic decisions through an easy-to-use web interface.

## Features
- College and course recommendations based on student preferences  
- Filter colleges by entrance exams, fees, location, and ratings  
- Search and compare colleges across India  
- View detailed college and course information  
- User-friendly and responsive interface  

## Tools Used
- Frontend: HTML, CSS, JavaScript  
- Backend: Python (Flask)  
- Database: MongoDB
